# Getting help

Use GitHub Issues for reproducible bugs and feature proposals. Before opening
an issue, search existing issues and include the browser, device, model,
spoken language, audio duration, and exact error message.

For translation-quality reports, include the language pair and a short,
synthetic example. Never upload private recordings, medical information,
personal transcripts, or secrets.

Use the security policy for vulnerabilities instead of a public issue. General
questions and implementation discussions belong in GitHub Discussions when
that feature is enabled for the repository.
